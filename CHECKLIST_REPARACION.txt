✅ CHECKLIST DE REPARACIÓN

┌─────────────────────────────────────────────────────────────────┐
│ ANTES DE COMENZAR                                               │
└─────────────────────────────────────────────────────────────────┘

[ ] Estar en el directorio: Proyecto_Analisis_Final\ANALISIS_COMPARATIVO
[ ] Tener Python 3.10+ instalado
[ ] Tener pip funcionando

┌─────────────────────────────────────────────────────────────────┐
│ PASO 1: REPARAR ARCHIVOS DAÑADOS                                │
└─────────────────────────────────────────────────────────────────┘

Elige UNA de estas opciones:

OPCIÓN A (AUTOMÁTICA - RECOMENDADA):
[ ] Doble-click en repair.bat
[ ] Espera a que termine
[ ] Presiona cualquier tecla

OPCIÓN B (MANUAL):
[ ] Ejecuta: copy requirements_new.txt requirements.txt
[ ] Ejecuta: del requirements_new.txt

OPCIÓN C (PYTHON):
[ ] Ejecuta: python repair_imports.py

┌─────────────────────────────────────────────────────────────────┐
│ PASO 2: INSTALAR DEPENDENCIAS                                   │
└─────────────────────────────────────────────────────────────────┘

[ ] Ejecuta: pip install -r requirements.txt
[ ] Espera a que termine (puede tomar varios minutos)
[ ] Verifica: pip list | grep Django (debe mostrar Django==6.0.4)

┌─────────────────────────────────────────────────────────────────┐
│ PASO 3: VERIFICAR PROYECTO                                      │
└─────────────────────────────────────────────────────────────────┘

[ ] Ejecuta: python manage.py check
[ ] Verifica: Debe decir "System check identified no issues"
[ ] Si hay errores, anota qué dice el error

┌─────────────────────────────────────────────────────────────────┐
│ PASO 4: PREPARAR BASE DE DATOS                                  │
└─────────────────────────────────────────────────────────────────┘

[ ] Ejecuta: python manage.py migrate
[ ] Espera a que termine
[ ] Debe mostrar: "Running migrations..." y completar

┌─────────────────────────────────────────────────────────────────┐
│ PASO 5: CREAR USUARIO ADMINISTRADOR                             │
└─────────────────────────────────────────────────────────────────┘

[ ] Ejecuta: python manage.py createsuperuser
[ ] Ingresa nombre de usuario (ej: admin)
[ ] Ingresa email (ej: admin@localhost)
[ ] Ingresa contraseña (mín 8 caracteres)
[ ] Confirma contraseña
[ ] Verifica: "Superuser created successfully"

┌─────────────────────────────────────────────────────────────────┐
│ PASO 6: EJECUTAR SERVIDOR                                       │
└─────────────────────────────────────────────────────────────────┘

[ ] Ejecuta: python manage.py runserver
[ ] Espera a ver: "Starting development server at http://127.0.0.1:8000/"
[ ] No cierres esta ventana (servidor debe seguir corriendo)

┌─────────────────────────────────────────────────────────────────┐
│ PASO 7: VERIFICAR QUE FUNCIONA                                  │
└─────────────────────────────────────────────────────────────────┘

En tu navegador:

[ ] Accede a: http://127.0.0.1:8000/
[ ] Deberías ver la página de login o dashboard
[ ] Si ves un error, anota qué dice

[ ] Accede a: http://127.0.0.1:8000/admin/
[ ] Inicia sesión con usuario/contraseña que creaste
[ ] Deberías ver el panel de administración

┌─────────────────────────────────────────────────────────────────┐
│ ¿TODO FUNCIONÓ? ✅                                              │
└─────────────────────────────────────────────────────────────────┘

Si llegaste hasta aquí sin errores:

[ ] ¡FELICIDADES! Tu proyecto está funcionando correctamente
[ ] El servidor sigue corriendo (no cierres la ventana)
[ ] Ahora puedes usar la aplicación normalmente

- Presiona CTRL + C en la ventana del servidor
