1. ¿Qué es BioSuelo?

BioSuelo es un sistema web de procesamiento y visualización de resultados microbiológicos de suelos agrícolas. Permite gestionar muestras de campo, cargar archivos de secuenciación molecular (16S rRNA para bacterias, ITS para hongos), procesar automáticamente los resultados y consultar el catálogo de microorganismos identificados.

Como administrador usted tiene acceso completo: puede crear, editar y eliminar cualquier registro del sistema, gestionar los usuarios y sus roles, y monitorear todo el flujo de trabajo desde la toma de muestras hasta los resultados taxonómicos.

El panel de control del sistema (Dashboard) muestra un resumen en tiempo real: muestras recientes, últimas cargas moleculares y los taxa más abundantes identificados.
🌾

2. Cultivos

Los Cultivos son los tipos de plantas agrícolas que se estudian (cacao, banano, maíz, etc.). Cada cultivo puede tener múltiples variedades o clones asociados.

Para crear un cultivo:
  1. En el menú lateral, haga clic en Muestras de Campo → Cultivos.
  2. Presione el botón + Agregar Cultivo (esquina superior derecha).
  3. Ingrese el Nombre (único en el sistema) y una Descripción opcional.
  4. Suba una fotografía desde su computadora (JPG, PNG, WEBP) o pegue un enlace externo en el campo URL de imagen. Si pega una URL, el sistema descarga la imagen automáticamente al servidor.
  5. Presione Guardar.
Si sube tanto archivo como URL, el archivo tiene prioridad. La imagen descargada queda almacenada en el servidor y es visible para todos los usuarios sin depender de sitios externos.
🌿

3. Variedades / Clones

Cada cultivo puede tener varias Variedades o Clones (ej.: Cacao → CCN-51, Nacional). Deben existir antes de registrar una muestra de suelo.

  1. Vaya a Muestras de Campo → Variedades / Clones.
  2. Presione + Agregar.
  3. Seleccione el Cultivo al que pertenece.
  4. Escriba el Nombre de la variedad o clon y una descripción opcional.
  5. Presione Guardar.
Puede filtrar la lista por cultivo usando el panel de filtros de la derecha para encontrar rápidamente las variedades de un cultivo específico.
🪱

4. Muestras de Suelo

Las Muestras de Suelo son el punto de partida de todo el análisis. Cada muestra tiene un código único, una ubicación geográfica y está vinculada a un cultivo y variedad específicos.

  1. Vaya a Muestras de Campo → Muestras de Suelo.
  2. Presione + Agregar Muestra de Suelo.
  3. Escriba un Código único e identificable (ej.: SUELO-CACAO-001).
  4. Seleccione el Cultivo. El selector de variedad/clon se actualizará automáticamente para mostrar solo las variedades de ese cultivo.
  5. Indique la Localidad, Finca / Lote y Altitud (msnm).
  6. Ingrese el Tipo de muestra (ej.: Suelo, Suelo Rizosférico).
  7. Presione Guardar.
Puede ver el historial completo de cambios de cada muestra haciendo clic en el botón Historial dentro del formulario de edición.
El código de muestra no puede repetirse. Defina una convención desde el inicio (ej.: TIPO-CULTIVO-NÚMERO) para mantener el orden a largo plazo.
🧬

5. Archivos Moleculares

Los Archivos Moleculares son los resultados crudos de la secuenciación (archivos CSV o Excel con datos taxonómicos). Al guardar un archivo, el sistema ejecuta automáticamente el pipeline de procesamiento y genera los resultados taxonómicos.

  1. Vaya a Secuenciación Molecular → Archivos Moleculares.
  2. Presione + Agregar Archivo Molecular.
  3. Seleccione la Muestra de Suelo a la que pertenece el archivo.
  4. Elija el Tipo de análisis: 16S para bacterias o ITS para hongos.
  5. Suba el archivo (CSV, TSV, XLSX, XLS).
  6. Presione Guardar. El pipeline se ejecutará al instante.
Si vuelve a subir un archivo para una muestra ya procesada, el sistema elimina los resultados anteriores y vuelve a procesar. Esto permite corregir errores sin duplicar datos.
El archivo debe tener columnas taxonómicas reconocibles (kingdom, phylum, class, order, family, genus, species, num_hits). Si el formato no es compatible, el sistema lo indicará con un mensaje de error.
🔬

6. Resultados Taxonómicos

Los Resultados Taxonómicos son generados automáticamente por el pipeline al cargar un archivo molecular. Esta sección es principalmente de consulta; no se recomienda editar registros individuales manualmente.

Cada resultado contiene la clasificación completa del microorganismo identificado: reino, filo, clase, orden, familia, género, especie, número de lecturas (hits) y porcentaje de abundancia relativa.

Use la barra de búsqueda para encontrar un género o especie específica en todos los archivos. Use los filtros de la derecha para ver solo los resultados de un tipo de análisis (16S o ITS).
📚

7. Catálogo de Microorganismos

El Catálogo es la base de referencia del sistema. Contiene microorganismos con su nivel taxonómico, marcador molecular, clasificación funcional y referencias bibliográficas. Se usa para contextualizar e interpretar los resultados.

Agregar un microorganismo manualmente:
  1. Vaya a Secuenciación Molecular → Catálogo de Microorganismos.
  2. Presione + Agregar.
  3. Ingrese el nombre científico, el nivel taxonómico, el marcador (16S / ITS) y la clasificación funcional.
  4. Presione Guardar.
Importar masivamente desde CSV / Excel:
  1. En la lista del catálogo, presione el botón verde Importar CSV / Excel.
  2. Suba un archivo con las columnas: nombre, nivel, marcador, clasificacion (obligatorias) y descripcion, referencia (opcionales).
  3. El sistema creará los registros nuevos y actualizará los existentes automáticamente.
Los valores permitidos para clasificacion son: benefico, fitopatogeno, neutral, sin_clasificar. Para marcador: 16S o ITS.
⚗️

8. Ensayos Microbiológicos

Los Ensayos Microbiológicos (módulo de Microbiología Clásica) registran experimentos de recuento o aislamiento de microorganismos realizados en laboratorio sobre muestras de suelo. A diferencia de la secuenciación molecular, estos datos provienen de cultivos en placas y medios selectivos.

  1. Vaya a Microbiología Clásica → Ensayos (Recuento / Aislamiento).
  2. Presione + Agregar.
  3. Seleccione la Muestra de Suelo relacionada.
  4. Ingrese el tipo de ensayo, la fecha y los parámetros del experimento.
  5. Presione Guardar.
🦠

9. Microorganismos Aislados

Los Microorganismos Aislados son los organismos identificados individualmente durante un ensayo microbiológico. Cada aislado está vinculado a un ensayo y puede tener información sobre su morfología, características bioquímicas y clasificación tentativa.

  1. Vaya a Microbiología Clásica → Microorganismos Aislados.
  2. Presione + Agregar.
  3. Seleccione el Ensayo del que proviene el aislado.
  4. Complete los campos de identificación y características.
  5. Presione Guardar.
👥

10. Usuarios

En Gestión → Usuarios puede ver, crear, editar y desactivar las cuentas de todos los usuarios del sistema. Los roles determinan qué secciones puede ver cada usuario.

Roles del sistema:
Rol Acceso en la plataforma
Administrador Acceso completo al admin y a todas las secciones del sistema.
Docente Acceso al dashboard, análisis, comparación e historial. Puede ver y comparar todos los resultados.
Estudiante Acceso al dashboard y consulta básica. No puede cargar ni modificar datos.
Crear un usuario nuevo:
  1. Presione + Agregar Usuario.
  2. Ingrese el correo electrónico (será el nombre de usuario).
  3. Asigne una contraseña temporal.
  4. Presione Guardar y continuar editando para asignar el Rol y nombre completo.
Restablecer contraseña de un usuario:
  1. Abra el usuario desde la lista.
  2. Haga clic en el enlace «Cambiar contraseña» que aparece en la parte superior del formulario.
  3. Ingrese y confirme la nueva contraseña.
  4. Presione Cambiar contraseña.
Para desactivar un usuario sin eliminarlo (recomendado), desmarque la casilla Activo. El usuario no podrá iniciar sesión pero su historial de datos se conserva.
🛠️

11. Herramientas generales del administrador

Búsqueda: En cada sección, use la barra de búsqueda superior para encontrar registros por nombre, código, correo o cualquier campo clave.

Filtros: El panel lateral derecho en cada listado permite filtrar por fecha, tipo, cultivo, rol u otros atributos. Los filtros se pueden combinar.

Historial de cambios: Dentro de cualquier registro que tenga pestaña Historial, puede ver quién hizo cada cambio, cuándo y qué valores tenía antes. Esto incluye Cultivos, Muestras de Suelo, Catálogo de Microorganismos y Usuarios.

Ordenar columnas: Haga clic en el encabezado de cualquier columna en los listados para ordenar ascendente o descendente.

Selección múltiple: Marque las casillas de la izquierda en varios registros y use el menú Acción para eliminarlos o exportarlos en lote.

Si tiene dudas sobre un campo en el formulario, posicione el cursor sobre el ícono de ayuda (?) junto al campo — algunos muestran instrucciones de ejemplo.
La acción Eliminar seleccionados es permanente y puede borrar datos relacionados en cascada. Desactive registros en lugar de eliminarlos cuando sea posible.
